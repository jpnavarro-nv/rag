# Singularity Deployment for NVIDIA RAG Blueprint

This directory contains Singularity/Apptainer deployment configurations for the NVIDIA RAG Blueprint.

## Structure

- `definitions/` - Singularity definition files (.def)
- `configs/` - Configuration files for Singularity deployment
- `scripts/` - Orchestration and deployment scripts
